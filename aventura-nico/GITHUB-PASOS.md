# Publicación en GitHub — Sprint 3

La devolución indica que todavía no hay repositorio remoto. Este paquete no puede crear un repositorio dentro de la cuenta personal del equipo sin iniciar sesión y autorizar GitHub.

1. Crear un repositorio nuevo en GitHub (por ejemplo, `ultimo-turno-nico`).
2. No inicializarlo con README si ya se va a subir esta carpeta completa.
3. Abrir una terminal de VS Code en la carpeta `aventura-nico`.
4. Ejecutar:

```bash
git init
git add .
git commit -m "Corrige observaciones del Sprint 3"
git branch -M main
git remote add origin https://github.com/USUARIO/REPOSITORIO.git
git push -u origin main
```

5. Reemplazar la URL de ejemplo por la URL real del repositorio.
6. Compartir el enlace del repositorio en la entrega y comprobar que sea público o que el docente tenga acceso.
7. Cada integrante debe realizar commits propios y dejar tareas/evidencias en el tablero.

No completar el enlace hasta que el repositorio remoto exista.
