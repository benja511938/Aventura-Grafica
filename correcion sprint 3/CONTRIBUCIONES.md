## Cómo trabajar con el repositorio

1. El dueño agrega a todos como colaboradores: *Settings → Collaborators → Add people*.
2. Cada integrante clona el repo y configura su identidad (una sola vez):
   ```
   git config user.name "Nombre Apellido"
   git config user.email "mail-de-su-cuenta-de-github"
   ```
3. Cada cambio va en un commit con mensaje claro (ej. `Agrega animación de Nico al final de derrota`) y se sube con `git push`.
4. Para ver los aportes de cada uno: `git shortlog -sne` y `git log --stat --format="%h %an %ad %s"`.
